# 케이스스터디 수정 안내

## 파일 구조
- `케이스스터디.html` — 페이지 전체(HTML + CSS + 텍스트). 이 파일 하나만 고치면 된다.
- `assets/*.jpg` — 화면 캡처 14장. HTML에서 `assets/파일명.jpg` 로 참조한다.

## 미리보기
이 폴더에서:
```
python3 -m http.server 8080
```
브라우저에서 http://localhost:8080/케이스스터디.html

## 섹션 구조 (수정할 위치 찾기)
- hero — 타이틀 / 한 줄 요약 / 메타 정보
- `01` 맥락 — 문제 정의
- `02` 접근 — AI에게 맡긴 것과 내가 정한 것의 경계
- `03` 설계 결정 — Decision 01~04
- `04` 사회자 화면 — 모바일 목업 6장 (assets 01~06)
- `05` 관리자 화면 — PC 목업 4장 (assets 08~11) + 카톡 캡처(07)
- `06` QA — 문제 발견 / 원인 / 해결 (assets 12)
- `07` 디자인 시스템 — 토큰 표 + Before/After (assets 13, 14)
- `08` 결과와 회고

## 이미지 교체할 때
1. 새 캡처를 `assets/` 에 같은 이름으로 덮어쓰기 (가로 640px 모바일 / 1500px PC 권장, JPEG q84)
2. 파일명을 바꿨다면 HTML 안의 `<img src="assets/...">` 도 같이 수정

## 주의
- 개인정보: 모든 캡처는 더미 데이터(신랑이름/신부이름/010-1234-1234/사회자1·2)로 교체됨.
  단 `11_DESKTOP-04`(사회자 링크)와 `13_BEFORE`(리디자인 전)는 실데이터라 블러 처리되어 있음. 블러를 제거하지 말 것.
- 다크모드 대응: 색상은 `:root` 의 CSS 변수로만 정의되어 있다. 하드코딩된 hex 를 새로 넣지 말고 기존 토큰(`--ink`, `--ink-2`, `--line`, `--accent` 등)을 쓸 것.
- 폰트는 Google Fonts CDN 을 쓴다. 오프라인에서는 시스템 폰트로 대체된다.

## 다시 공유 링크로 만들려면
수정이 끝난 뒤 이 폴더를 Netlify 에 드래그&드롭 하거나, 이미지를 다시 base64 로 인라인해서 단일 HTML 로 합치면 된다.
